API cheat sheet

webgame reads like pygame: Rect, Surface, draw.rect/circle/line, event.get(), key.get_pressed(), font.SysFont. One difference — since nothing can block the browser's main thread, the clock has to be awaited: 

dt_ms = await clock.tick(60)   # webgame — note the await
dt_ms = clock.tick(60)         # real pygame — no await

Want real pygame instead — more of the API, actual sprite groups, sound, the works? The games page covers the pygbag path, which compiles a real pygame script ahead of time. That one needs a local Python install to build; this page never does.

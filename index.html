Why not tkinter?

tkinter opens a native desktop window — it has no browser equivalent, so it can't run on a page like this one. Everything here targets the browser directly instead: the sandbox uses Pyodide for general-purpose code, and games use pygbag to compile pygame to WebAssembly with a canvas in place of a window.

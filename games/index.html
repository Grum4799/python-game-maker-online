Building in-browser (no install)

Head to Make — it's a code editor and live canvas in one page. Games written there use the site's own webgame module, a pygame-style API (Rect, Surface, draw, events, a frame clock) that runs directly under Pyodide. Nothing to install, nothing to push — your code is saved to the browser as you type.

Building the advanced way (real pygame)

Drop a pygame script (written with the async main-loop pattern pygbag expects) into games/<your-game>/main.py. The included GitHub Actions workflow builds every game with pygbag on each push and commits the compiled output, so a card added here just needs to point at games/<your-game>/build/web/index.html. See games/dodger/main.py for a working example, and the repo README for the full pygbag walkthrough. This path needs a local Python install to build — the in-browser editor above doesn't.

tkinter and other native-GUI libraries can't run here — see the home page for why
